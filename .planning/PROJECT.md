# Quran Arabic Learner

## What This Is

Веб-сервис для изучения арабского языка через флэш-карточки на основе слов из 30-го джуза Корана. Пользователь регистрируется, учит слова через систему интервальных повторений (spaced repetition) и отслеживает свой прогресс.

## Core Value

Флэш-карточки со словами 30-го джуза с алгоритмом spaced repetition — всё остальное второстепенно.

### Active

### Out of Scope

- Весь Коран (1-29 джуз) — слишком большой объём для v1, начинаем с 30-го джуза
- Мобильное приложение — только веб
- Аудио тецвид / озвучка чтецом — пока только текст
- Социальные фичи (лидерборды, друзья, сообщество) — не нужно для курсовой
- NLP/морфологический разбор арабских слов — слишком сложно для v1

## Context

- **Тип проекта:** Курсовая работа, КФУ, защита до конца мая 2026
- **30-й джуз (Juz Amma):** ~37 сур, ~564 аята, ~2000 уникальных слов — наиболее читаемая часть Корана, идеально для начинающих
- **Данные:** Бесплатный API alquran.cloud или локальная SQLite БД с текстом 30-го джуза + переводы
- **Деплой:** Vercel (фронтенд), Railway или Render (бэкенд FastAPI), PostgreSQL в облаке

## Constraints

- **Timeline:** До конца мая 2026 (~2.5 месяца)
- **Scope:** Только 30-й джуз Корана в v1
- **Stack:** React (фронтенд) + FastAPI/Python (бэкенд) + PostgreSQL
- **Deployment:** Vercel + Railway/Render — всё бесплатно или дёшево
- **RTL:** Арабский текст требует особой поддержки (dir="rtl", шрифты Amiri/Scheherazade)
