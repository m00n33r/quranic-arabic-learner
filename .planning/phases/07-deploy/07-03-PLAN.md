# Quran Arabic Learner

Веб-сервис для изучения арабского языка через слова 30-го джуза Корана с использованием интервального повторения (SM-2).

## Стек

- **Frontend**: React + TypeScript + Vite + Tailwind CSS
- **Backend**: FastAPI + SQLAlchemy + Alembic
- **БД**: PostgreSQL
- **Алгоритм**: SuperMemo-2 (SM-2) для интервального повторения
- **Деплой**: Vercel (frontend) + Railway (backend)

## Быстрый старт

### Требования
- Python 3.12+
- Node.js 18+
- Docker + Docker Compose

### Запуск через Docker

```bash
cp backend/.env.example backend/.env
docker compose up -d
cd backend && source .venv/bin/activate && alembic upgrade head
python scripts/seed_db.py  # Загрузить слова 30-го джуза
cd frontend && npm install && npm run dev
```

Открой http://localhost:5173

### Запуск без Docker

```bash
# Backend
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -e .
cp .env.example .env  # Настрой DATABASE_URL
alembic upgrade head
uvicorn app.main:app --reload

# Frontend (в отдельном терминале)
cd frontend
npm install
npm run dev
```

## Функции

- Флэш-карточки с арабским текстом (RTL + шрифт Amiri)
- Анимация переворота карточки (CSS 3D)
- Алгоритм SM-2: интервальное повторение для оптимального запоминания
- Регистрация и авторизация (JWT)
- Статистика прогресса: слова выучены, серия дней, точность
- 30-й джуз Корана (~560 уникальных слов)

## Деплой

- Backend: см. [backend/DEPLOY.md](backend/DEPLOY.md)
- Frontend: см. [frontend/DEPLOY.md](frontend/DEPLOY.md)
