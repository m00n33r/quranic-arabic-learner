**Railway деплой:**
1. railway login (CLI) или через GitHub в web dashboard
2. railway new → выбрать репозиторий
3. Добавить PostgreSQL сервис (railway add)
4. Задать env variables через Railway dashboard или CLI
5. Railway автоматически запустит Dockerfile

**Env variables для Railway:**
```
DATABASE_URL=<Railway PostgreSQL connection string>
SECRET_KEY=<сгенерировать: python -c "import secrets; print(secrets.token_hex(32))">
ENVIRONMENT=production
DEBUG=false
ALLOWED_ORIGINS=["https://<your-vercel-app>.vercel.app"]
```

**Alembic в production:**
- Нельзя запускать `alembic upgrade head` внутри контейнера напрямую
- Railway позволяет задать стартовую команду: `alembic upgrade head && uvicorn app.main:app --host 0.0.0.0 --port $PORT`

**Seed данных:**
- После деплоя запустить seed скрипт для загрузки слов 30-го джуза
- Railway CLI: `railway run python scripts/seed_db.py`

## Предварительно

## Шаги деплоя

### 1. Создать проект на Railway

```bash
cd /path/to/course_project
railway init
# Выбери: Create new project
# Имя: quran-arabic-learner
```

### 2. Добавить PostgreSQL

В Railway dashboard → Add Service → Database → PostgreSQL

Или через CLI:
```bash
railway add --plugin postgresql
```

### 3. Получить DATABASE_URL

```bash
railway variables
# Скопируй DATABASE_URL (формат: postgresql://...)
```

### 4. Задать env variables

В Railway dashboard → Variables → Add:
```
SECRET_KEY=<твой_секретный_ключ>
ENVIRONMENT=production
DEBUG=false
ALLOWED_ORIGINS=["https://YOUR-VERCEL-APP.vercel.app"]
```

DATABASE_URL Railway добавляет автоматически из PostgreSQL сервиса.

### 5. Задеплоить

```bash
railway up --service backend
```

Или настрой автодеплой из GitHub в Railway dashboard.

### 6. Запустить seed (первый раз)

```bash
railway run --service backend python scripts/seed_db.py
```

### 7. Проверить

```bash
# Получить публичный URL
railway domain

# Проверить health
curl https://YOUR-APP.railway.app/health
```

## Переменные окружения

| Variable | Description | Example |
|----------|-------------|---------|
| `DATABASE_URL` | PostgreSQL URL (auto from Railway) | `postgresql+psycopg2://...` |
| `SECRET_KEY` | JWT secret (32+ chars random) | `abc123...` |
| `ENVIRONMENT` | App environment | `production` |
| `DEBUG` | Debug mode | `false` |
| `ALLOWED_ORIGINS` | CORS origins (JSON array) | `["https://app.vercel.app"]` |

## Troubleshooting

- **502 Bad Gateway**: проверь логи `railway logs --service backend`
- **Миграции не прошли**: `railway run alembic upgrade head`
- **CORS ошибки**: проверь ALLOWED_ORIGINS включает твой Vercel URL
