**Prod vs Dev конфигурация:**
- `ENVIRONMENT`: "development" | "production"
- В production: DEBUG=False, CORS только для Vercel домена
- SECRET_KEY должен быть длинным случайным (не захардкожен!)
- DATABASE_URL: postgresql+psycopg2://... (не sqlite!)
- ALLOWED_ORIGINS: ["https://<your-app>.vercel.app"] в prod

**Dockerfile оптимизация (multi-stage):**
- Stage 1 (builder): pip install
- Stage 2 (runtime): только нужные файлы, non-root user
- Цель: образ < 200MB

**Vercel конфигурация:**
- frontend/vercel.json: rewrites /api/* → backend URL
- VITE_API_URL env variable для prod API URL

**Railway конфигурация:**
- Использует Dockerfile или Nixpacks (Dockerfile предпочтительнее — детерминировано)
- PORT env variable — Railway задаёт автоматически
- Команда: uvicorn app.main:app --host 0.0.0.0 --port $PORT
</context>

```python
from pydantic_settings import BaseSettings
from typing import list


class Settings(BaseSettings):
    # Database
    database_url: str = "postgresql+psycopg2://postgres:postgres@localhost:5432/quran_learner"

    # JWT
    secret_key: str = "change-me-in-production-use-long-random-string"
    algorithm: str = "HS256"
    access_token_expire_minutes: int = 60 * 24 * 7  # 7 дней

    # App
    environment: str = "development"
    debug: bool = True

    # CORS — список разрешённых origins
    allowed_origins: list[str] = [
        "http://localhost:5173",
        "http://localhost:3000",
    ]

    @property
    def is_production(self) -> bool:
        return self.environment == "production"

    model_config = {"env_file": ".env", "env_file_encoding": "utf-8"}


settings = Settings()
```

Обновить backend/app/main.py — использовать allowed_origins из settings:

Перезаписать backend/Dockerfile:
```dockerfile
# Stage 1: Сборка зависимостей
FROM python:3.12-slim as builder

WORKDIR /build

# Установить системные зависимости для psycopg2
RUN apt-get update && apt-get install -y --no-install-recommends \
    libpq-dev gcc \
    && rm -rf /var/lib/apt/lists/*

COPY pyproject.toml .
RUN pip install --no-cache-dir --upgrade pip \
    && pip install --no-cache-dir build \
    && pip install --no-cache-dir .

# Stage 2: Runtime образ
FROM python:3.12-slim as runtime

# Системные зависимости только для runtime
RUN apt-get update && apt-get install -y --no-install-recommends \
    libpq5 \
    && rm -rf /var/lib/apt/lists/*

# Non-root пользователь для безопасности
RUN useradd --create-home --shell /bin/bash appuser
USER appuser
WORKDIR /home/appuser/app

# Скопировать установленные пакеты из builder
COPY --from=builder /usr/local/lib/python3.12/site-packages /usr/local/lib/python3.12/site-packages
COPY --from=builder /usr/local/bin /usr/local/bin

# Скопировать приложение
COPY --chown=appuser:appuser . .

# Railway задаёт PORT автоматически
ENV PORT=8000
EXPOSE $PORT

# Health check
HEALTHCHECK --interval=30s --timeout=10s --start-period=5s --retries=3 \
    CMD python -c "import urllib.request; urllib.request.urlopen('http://localhost:${PORT}/health')"

CMD uvicorn app.main:app --host 0.0.0.0 --port ${PORT}
```

```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  server: {
    port: 5173,
    proxy: {
      '/api': {
        target: 'http://localhost:8000',
        changeOrigin: true,
      },
    },
  },
  build: {
    outDir: 'dist',
    sourcemap: false,  // не нужны в prod
  },
})
```

Обновить frontend/src/api/client.ts — поддержка VITE_API_URL:
```typescript
import axios from 'axios'

// В production через vercel.json proxy → относительный /api/v1
// В dev через vite proxy → тоже относительный /api/v1
const API_BASE = '/api/v1'

export const apiClient = axios.create({
  baseURL: API_BASE,
  headers: { 'Content-Type': 'application/json' },
})

apiClient.interceptors.request.use((config) => {
  const token = localStorage.getItem('access_token')
  if (token) {
    config.headers.Authorization = `Bearer ${token}`
  }
  return config
})

apiClient.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      localStorage.removeItem('access_token')
      window.location.href = '/login'
    }
    return Promise.reject(error)
  }
)
```
